# Decent School Furniture — Advanced Frontend Demo

Responsive multi-page static website built with HTML, CSS, JavaScript and JSON. No backend is included. Forms validate but clearly explain that messages are not sent until a real submission endpoint is connected.

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Install the free **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

JSON loading uses `fetch()`, so use a local HTTP server rather than opening the HTML as `file://`.

## Pages
Home, About, Services, Products, dynamic Product Details (`product.html?id=student-desk`), Gallery, FAQ, Contact, Request a Quote and Privacy Policy.

## Customize
Edit `data/business.json` and `data/products.json`. Replace stock imagery with licensed/authorized photos. Add verified contact details, business address, hours, real reviews and policy text before launch. The logo is a custom editable SVG concept.
